# 吕家添 · 个人作品集原型

使用简体中文制作的响应式个人网站，面向产品经理求职与个人介绍。页面重点呈现实习经历、创业项目、产品观点、联系方式、工作室身份与中英文原版简历。

## 本地预览

直接打开 `index.html`，或在本目录运行 `python3 -m http.server 8765`，然后访问 `http://localhost:8765`。网站没有构建步骤或第三方运行时依赖。

## V3 视觉方向

- 首页参考高端硬件与创意机构官网的“大幅视觉 + 叠加文字”结构，使用闪稻路演第六页提取的透明动漫人物素材 `assets/jiatian-character.png`；它是个人视觉化形象，不代表真人照片。
- 导航默认叠在首屏上，滚动超过首屏约 70% 后自动变为固定的磨砂玻璃栏；手机端提供四项快捷导航。
- 首屏包含遮罩揭开、压缩后归位、人物模糊到清晰、轨道线旋转和慢速光晕；滚动模块使用大幅英文标题、错峰卡片、光带 reveal 与图片轻微动效。
- 动效使用原生 CSS、IntersectionObserver 和 requestAnimationFrame，保持离线可预览、低依赖与可关闭；导航中的“暂停动效”会停用动画，系统减少动效设置也会生效。

## 文件结构

- `index.html`：页面内容与入口。
- `styles.css`、`v2.css`、`v3.css`：基础布局、深色主题与 V3 动效覆盖。
- `app.js`：案例弹窗、邮箱复制、阅读进度、悬浮导航、滚动 reveal 与人物视差。
- `assets/`：项目图片、图标、动漫人物、工作室标识和用户提供的简历原件。

中英文下载分别为 `assets/呂家添-產品經理 VC .pdf` 和 `assets/VC_JiaTianLu(PM) .pdf`，与用户提供的源 PDF 内容一致。不要将旧版改写简历作为下载文件分发。

## 信息口径

- 实习经历以“浙江省某数据安全标杆企业”匿名展示。AI 方向标注为策略配置辅助的应用探索；英语语种敏感检索优化注明已上线。商业敏感的规则、实现细节和客户数据未展示。
